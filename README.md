# MindVibe 2.0

Voice-Based Four-Tier Stress Analysis Using Guided K-Means and CNN.

## Overview
MindVibe 2.0 analyzes uploaded audio and predicts one of four stress categories:
- Not Stressed
- Low Stress
- Medium Stress
- High Stress

## Run locally
Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Model
The trained CNN model is stored at metadata/cnn_model_v2.keras.

## Disclaimer
This is an experimental academic project, not a clinical assessment or diagnosis.
